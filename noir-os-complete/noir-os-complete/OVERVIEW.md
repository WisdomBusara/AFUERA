# Noir OS (Afuera)

One Next.js app: a personal operating system (projects, tasks, daily brief) plus a content
workspace (board, calendar, campaigns, approvals, analytics, assets, brand kit, automations, AI).

- **The app:** `noir-os-complete/noir-os-complete/01-nextjs-app/` — start with its `README.md`.
- **Hosting:** `01-nextjs-app/deploy/TUNNEL.md` (VPS + Cloudflare Tunnel, live at https://afuera.wisdombusara.com).
- **Original design prototype:** `noir-os-complete/noir-os-complete/02-interactive-prototype/` (static mock-up, not the product).

The app ships with no demo data: `npm run db:admin` creates the first super admin and an empty
workspace, and everything else is created in the UI.
